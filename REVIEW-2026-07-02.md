# Review findings — 2026-07-02

Consolidated from twelve reviewers over the agent-readiness batch: Claude's
8-angle finder fleet (reuse angle reported; other angles superseded by
overlap) and four Codex CLI personas (CTO, senior engineer, UX engineer,

## Correctness

| # | Finding | Source | Status |
|---|---------|--------|--------|
| C1 | `pollMessages` watermarked on `sentAt`; a message synced later with an older timestamp is skipped forever | senior, CTO | ✅ cursor now rides a store-stamped ingestion sequence (`StoredMessage.seq`; SQLite `rowid`, memory counter) — ordering no longer trusts sender clocks; also removes the same-timestamp seen-set (C10) |
| C2 | `cone messages`/`wait` ignored `sync().ok` → false exit 3 "nothing new" on network failure | senior | ✅ failed sync now exits 1 with code `SYNC_FAILED` |
| C3 | Idempotency keys were global — reusing a key for a different recipient silently suppressed the send and returned the other peer's messageId | senior | ✅ ledger records the resolved scope; a key reused with a different recipient throws `IDEMPOTENCY_CONFLICT` |
| C4 | `cone wait` had an unsubscribed gap: mail arriving between the drain-poll and stream subscription was missed until timeout | senior | ✅ re-syncs and re-polls once after subscribing |
| C5 | Idempotency recorded after publish (crash window) and SKILL overclaimed "never double-sends" past the 200-entry cap | senior, CTO | ✅ claim-before-send: a `pending` record is written first; a retry finding `pending` throws `IDEMPOTENCY_IN_FLIGHT` (at-most-once, honestly); SKILL states the real guarantee and the cap |
| C6 | Reads surfaced the raw app-JSON envelope (`{type,value,replyTo}`), `replyTo` wasn't first-class, poll output lacked `conversationKind` | senior, agent | ✅ view-time unwrap: `json` is the sender's payload, `replyTo` and `conversationKind` are ConeMessage fields; listen/messages/wait/inbox read agree |
| C7 | `listen --once` timeout exited 1/`TIMEOUT` (vs the documented exit-3 contract) and listen didn't filter control envelopes | agent | ✅ exit 3 on timeout; control envelopes no longer emitted |
| C8 | `RENDEZVOUS_REJECTED` returned but undocumented; SKILL's `wait` recipe omitted `--cursor-name` (replays) | senior, agent | ✅ codes documented (incl. new `SYNC_FAILED`, `IDEMPOTENCY_*`, `NETWORK_UNREACHABLE`); recipe fixed |
| C9 | Non-numeric `--timeout-ms` parsed to NaN → infinite hang | senior | ✅ shared validation throws `USAGE` (wait, listen, group invite/join) |
| C10 | Cursor seen-set unbounded at one timestamp | senior | ✅ eliminated by the C1 sequence design |
